Problem Statement — ATM Simulator
Managing basic banking transactions manually can be time-consuming and may lead to errors, incorrect calculations, or difficulty in keeping track of the available account balance. Therefore, there is a need for a simple computerized system that can efficiently handle common ATM operations.

The ATM Simulator is developed using Python to provide an easy and user-friendly way to perform basic banking transactions such as checking account balance, depositing money, and withdrawing money. The system validates transaction amounts and prevents invalid operations, such as depositing or withdrawing zero or negative amounts and withdrawing more money than the available balance.

The system uses Object-Oriented Programming (OOP) concepts to organize the ATM operations and user interaction. It reduces manual effort, improves transaction handling, and provides a simple and organized approach to simulating basic ATM functionality through a console-based interface.
